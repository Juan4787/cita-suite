# Evidencia local de configuración de reservas

Las capturas y browser.json corresponden a datos sintéticos y Auth simulado. validation.json resume los recibos de comprobación. El cierre independiente aceptó las cuatro correcciones detalladas en el informe. No contiene tokens, credenciales ni pacientes reales. El detector conserva su advertencia sobre Inter, fuente existente.

La fixture no implementa Realtime; se contabilizan sus advertencias aparte. No equivale a evidencia de producción, Safari ni lector de pantalla físico. El informe padre explica repetición, alcance y publicación.

Los manifiestos y comprobantes del despliegue final se generan después del commit y quedan fuera del historial de este paquete para evitar otro build que sólo agregue documentación.
