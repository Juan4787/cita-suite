# Contrato de dirección: configuración del turnero

THESIS: Una profesional nueva encuentra cada función por la tarea que quiere hacer. Reserva online permite compartir la agenda y definir cuándo puede reservar el paciente. La configuración de una persona vive en Equipo, dentro de su perfil.

OWN-WORLD: Conservar el sistema oscuro existente de Cita Suite: Inter, fondo #0b1626, superficies azul oscuro, acento violeta #8b5cf6. La identidad se expresa en controles y estados consistentes. No se reemplaza la marca ni se inventan hechos del consultorio.

STORY: Configuración → Reserva online → enlace para pacientes y reglas. Configuración → Datos del consultorio → Contacto en tu web. Configuración → Archivos de pacientes. Equipo → profesional → Perfil / Servicios y aranceles / Horarios / Preguntas al paciente. Integrar una web es opcional y se abre desde una página separada.

FIRST VIEWPORT: El título Reserva online, su estado y un enlace listo para compartir preceden las reglas. No hay una hilera de accesos a profesionales, aranceles, cuestionarios o integración. Una acción de copia, una de vista del paciente y una de activación/pausa explican las acciones frecuentes sin un manual.

FORM: Listas y filas para tareas y datos habituales; formularios con agrupaciones cortas, campos visibles y opciones secundarias plegadas. En celular se apilan, sin scroll horizontal. Selectores, calendarios, casillas, diálogos y estados tienen acabado propio, foco visible y acceso por teclado. Conservar valores, claves, revisiones y permisos al separar las pantallas. Formularios progresivos conservan envío sin JS cuando procede; el aviso al cerrar/recargar la pestaña sigue siendo una protección del navegador.

Solicitud explícita: rediseño profundo de arquitectura, orden, lenguaje y visual; no compensar con paredes de texto; no dejar controles con estilado nativo. Cursos/noticias aplazados. Nada de datos inventados ni cambios reales de configuración por las pruebas.

Implementación de código sobre el sistema existente; sin maqueta aprobada, sin reemplazo de mundo ni dirección gráfica de marketing. PRODUCT.md es el contrato de producto. Las capturas y resultados son locales, con datos sintéticos y Auth simulado.
