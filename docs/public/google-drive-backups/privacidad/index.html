Política de privacidad

Esta política corresponde exclusivamente a Cita Suite Respaldos, herramienta privada para administrar copias de seguridad en Google Drive. Su automatización se encuentra en configuración; los tratamientos descritos a continuación aplican cuando el titular autorice y active ese acceso.

Datos y permisos de Google

El acceso previsto se limita a archivos creados por esta herramienta o seleccionados expresamente para ella. Comprende el contenido y los metadatos necesarios para administrar esas copias, como nombre, identificador, tamaño y fecha. También se comprobará la cuenta de Drive autorizada para evitar enviar copias a una cuenta equivocada.

El único propósito de ese acceso es almacenar, verificar, recuperar y aplicar la retención de los respaldos. No se solicita acceso a Gmail, contactos ni eventos de Calendar para esta tarea.

Contenido de las copias y protección

Las copias de una instalación de Cita Suite pueden contener información administrativa, datos de pacientes e historia clínica. Son confidenciales. Antes de habilitar la ejecución periódica se debe verificar su cifrado previo al envío, la custodia separada de la clave y una recuperación de prueba.

Las credenciales y los archivos de respaldo no se publican en este sitio ni en el repositorio de estas páginas. El sitio no tiene formularios para recibirlos.

Uso y proveedores

Los datos de Google se usarán exclusivamente para operar los respaldos autorizados. No se venderán ni se usarán para publicidad, elaboración de perfiles o entrenamiento de modelos de inteligencia artificial.

Google Drive alojará las copias privadas. Si la automatización se ejecuta con un proveedor de cómputo externo, deberá configurarse como un entorno protegido con acceso limitado y eliminación de sus archivos temporales. Ese acceso no autoriza una publicación de datos ni un uso distinto del respaldo.

El uso de información recibida de las APIs de Google se ajustará a la Política de Datos de Usuario de los Servicios de API de Google y a los requisitos de uso limitado que correspondan.

Conservación, revocación y eliminación

El administrador definirá la retención antes de activar las copias periódicas. No se establece una conservación ilimitada. La eliminación de copias deberá respetar esa retención y la posibilidad de recuperar los archivos conservados.

El titular puede retirar la autorización desde las conexiones de su cuenta de Google. Esto impide nuevos accesos mediante esa autorización; no elimina por sí solo las copias que ya estén guardadas en Drive. El titular puede administrarlas en su propia cuenta y solicitar la eliminación de credenciales conservadas por la herramienta.

Visitas a este sitio

Estas páginas estáticas se alojan en GitHub Pages. No incorporan formularios, anuncios, scripts de seguimiento ni analítica propia. GitHub registra datos técnicos de las visitas, como la dirección IP, conforme a su política de privacidad.
