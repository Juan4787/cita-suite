# Páginas informativas de Cita Suite Respaldos

Fuente pública mínima para los enlaces de marca del cliente OAuth de respaldos. Sólo contiene información del propósito, privacidad y condiciones operativas. La automatización continúa en configuración.

Publicación prevista: GitHub Pages de `Juan4787/cita-suite-respaldos-info`, repositorio público exclusivo de estas páginas. El código de ejecución y las copias no pertenecen a ese repositorio.

Archivos permitidos: `.nojekyll`, `index.html`, `styles.css`, `privacidad/index.html`, `terminos/index.html` y este README. Sin compilador, paquetes, formularios ni JavaScript. No copiar credenciales, datos clínicos, manifiestos, copias, claves de cifrado o recibos privados.

Estado de publicación y comprobaciones: `docs/architecture/acceso-google-drive-respaldos.md` en el repositorio principal de Cita Suite. Publicar estos enlaces no demuestra aprobación de marca por Google ni autorización de Drive.
